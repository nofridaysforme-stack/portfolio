# Payload CMS Directory

This directory contains all Payload CMS configuration, collections, blocks, and globals.

## Structure

- `collections/` - Content collections (Projects, Blog, Media, etc.)
- `blocks/` - Reusable content blocks for page building
- `globals/` - Global settings (Navigation, Footer, SEO, etc.)
- `fields/` - Reusable field configurations
- `hooks/` - Lifecycle hooks for collections
- `payload.config.ts` - Main Payload configuration

## Collections

Define your content types here (Projects, Blog Posts, Case Studies, etc.)

## Blocks

Reusable content blocks for flexible page layouts using Payload's block fields.

## Globals

Site-wide settings and configurations accessible from the admin panel.
