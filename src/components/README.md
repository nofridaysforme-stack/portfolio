# Components Directory

React components organized by category.

## Structure

### `/ui`
Reusable UI components (buttons, cards, forms, etc.)
- Design system primitives
- Form elements
- Interactive elements

### `/blocks`
Content blocks that correspond to Payload CMS blocks
- Hero sections
- Feature grids
- Testimonials
- Call-to-action sections

### `/layout`
Layout components (header, footer, navigation, etc.)
- Header with navigation
- Footer
- Sidebar
- Container wrappers

### `/portfolio`
Portfolio-specific components
- Project cards
- Project gallery
- Case study layouts
- Skills showcase
- About sections

## Guidelines

- Use TypeScript for all components
- Implement proper prop types
- Use Tailwind CSS for styling
- Support dark/light themes where applicable
